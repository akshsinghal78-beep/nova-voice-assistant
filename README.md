# 🤖 Nova - AI Voice Assistant

Nova is an intelligent AI-powered voice assistant designed to perform tasks through voice commands. It can listen to user instructions, process requests, and respond with voice output, making human-computer interaction faster and more convenient.

## ✨ Features

- 🎤 Voice Command Recognition
- 🗣️ Text-to-Speech Responses
- 🔍 Web Search Functionality
- 🌦️ Weather Information
- ⏰ Time and Date Updates
- 📂 Open Applications and Websites
- 🎵 Play Music
- 📧 Basic Automation Tasks
- 🤖 AI-Powered Conversations

## 🛠️ Tech Stack

- Python
- SpeechRecognition
- pyttsx3
- OpenAI API (Optional)
- Wikipedia API
- Webbrowser Module
- Datetime Module
- Requests Library
